Backend Security & Data Isolation Architecture

Derived Identity Enforcement: All student dashboard queries derive student USN strictly from verified server-side session authentication tokens. Client-supplied USN tampering in URL or API payloads is strictly prohibited.
Zero Direct Password Storage: Passwords and OTPs are managed cryptographically by Firebase Authentication and are never stored in the application's local database.
Module 1 Isolation: Official placement marks and HOD statuses are strictly read-only for students. Practice quiz scores and mock interview results are stored in separate training tables and will never overwrite coordinator records.
